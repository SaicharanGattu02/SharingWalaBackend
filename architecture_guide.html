1. Executive Summary & Architecture Philosophy

The SHARE2GO backend powers both the SHARE2GO Mobile App (for passengers and drivers) and the SHARE2GO Admin Portal (for platform operators).

It is designed as a Modular Monolith under Clean Architecture principles. This ensures:

🛡️ 1. Platform Administration Domain
Complete administrative oversight: user management, KYC approvals, ride cancellations, SOS incident center, dynamic pricing, and system audits.
/api/v1/admin/* /api/v1/admin/sos/*
👤 2. User Side (Passenger Persona)
Commuter experience: ride search with origin/destination filters, seat booking, booking history, ratings, trusted contacts, and stranger meetups.
/api/v1/user/* /api/v1/stranger/*
🚗 3. Rider Side (Driver / Host Persona)
Vehicle owner experience: driver verification KYC, vehicle fleet, ride offering, passenger booking management (accept/reject), and trip controls.
/api/v1/rider/*
🛠️ 4. Centralized Common Services
Shared cross-cutting platform engines: Phone OTP authentication, real-time chat, universal uploads, emergency SOS, and commute communities.
/api/v1/auth /api/v1/chat /api/v1/upload

4. Clean Architecture Inside Each Module

Every feature module in src/modules/<feature>/ contains strictly 4 files:

Layer File Responsibility Rule
*.routes.js HTTP endpoint definitions, middleware attachment No business logic; delegates directly to controller
*.controller.js Extracts params/body, calls service, returns ApiResponse Always wrapped inside asyncHandler
*.service.js Pure business logic, validation checks, database queries Only layer that talks to prisma singleton
*.validation.js Zod input schemas for query, params, and body Executed by validate(schema) middleware

7. Summary: 5 Golden Rules for Developers

Rule Requirement Why It Matters
1. Database Singleton Always import prisma from src/config/db.js Prevents MySQL connection pool exhaustion in dev hot-reloads.
2. Error Handling Throw new ApiError(statusCode, message) Ensures clean JSON error responses without crashing the server.
3. Response Standard Return new ApiResponse(statusCode, data, message) Provides a predictable contract: { success, statusCode, message, data }.
4. Async Safety Wrap all controllers in asyncHandler(...) Eliminates boilerplate try/catch blocks across the codebase.
5. Validation Define Zod schemas in *.validation.js Guarantees strictly typed input validation before hitting services.
